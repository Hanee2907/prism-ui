Accessibility

Glass and rainbows are easy to get wrong. Prism is built so everyone can still read and use it.

  • Contrast, tested. 30 automated tests check every text and background pair in both themes against WCAG AA, using the solid colour behind the glass, so text stays readable even with nothing colourful behind it.
  • Two spectrums. The bright one is only for glows, rings and toggles. Anything with text on it uses the deep spectrum, where white text reaches at least 4.9:1.
  • Real elements. Buttons are buttons, switches are checkboxes, the modal is a native dialog and the accordion is details and summary, so keyboards and screen readers work without extra code.
  • Visible focus. A thick violet ring shows where the keyboard is, everywhere.
  • Big targets. Buttons and fields are at least 46px tall.
  • Calm motion. One switch makes every animation near-instant, and followSystemMotion() turns it on from the visitor's system setting.

Get started

Two lines to glow

Add the fonts and the stylesheet, put class="pr" on your body (and the mesh if you like), then copy any component from this page.

✓
Need lens light, tabs, modals or toasts? Add the script and call PrismUI.init(). Everything else is pure CSS.
